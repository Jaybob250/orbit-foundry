# orbit-🌌 Orbit Foundry

Build your orbital scrapyard empire!

▶️ Play Orbit Foundry

Orbit Foundry is a space-themed incremental idle game. Collect scrap, build automated facilities, research upgrades, and expand across the solar system.

🎮 Gameplay

* Tap asteroids to collect scrap.
* Buy facilities for passive income.
* Research technologies to boost production.
* Unlock new sectors for bigger multipliers.
* Reach milestones for bonus scrap.

🏭 Facilities

1. Scout Drone – Small drones that collect loose debris.
2. Salvage Skiff – Crewed ships that salvage wreckage.
3. Smelter Platform – Processes wreckage into valuable scrap.
4. Orbital Foundry – A huge automated manufacturing station.

🔬 Research

* Magnetic Cutter
* Twin Rotor Drones
* Thermal Recycling
* Deep-Space Scanners
* Quantum Forging

🪐 Sectors

Earth Orbit → Lunar Wreckfield → Mars Graveyard → Jupiter Scrapyard

💾 Saving

Progress is saved automatically using your browser’s Local Storage.

Save key: orbit_foundry_save

Progress is stored per browser and device. Clearing browser data may erase your save.

🛠️ Built With

Pure HTML, CSS and JavaScript.

* Single HTML file
* No build step
* No external dependencies
